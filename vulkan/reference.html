Code reference

Lookup tables extracted from the sources by tools/extract.py, one row per item, each linked to its definition at the pinned commit. Use the tabs, filter as you type, and link to any row: the address bar keeps the tab and filter.

The reference needs JavaScript and assets/data/reference.js.

How these tables are made, and their limits

  • Entry points: names come from XGL's DispatchTable::Init. "First call in its body" is the first method call found in the implementation, resolved to its class where the handle conversion makes that clear. It is a pointer for reading, not a full call graph.
  • PAL interfaces: public methods of the I* classes in pal/inc/core, with the first sentence of each doc comment.
  • Settings: every setting, and every field of struct settings, in XGL's and PAL's settings files. Defaults are shown as written there; some differ per OS.
  • libdrm and ioctls: ioctl names are the ones literally present in each function body. Calls through helpers show up under "Calls" rather than "Ioctls".
  • PM4 opcodes: "refs" counts lines in each hardware layer that mention the opcode, including table entries.
  • Extensions: the condition shown is the nearest enclosing if; deeper conditions and runtime checks elsewhere are not captured.
