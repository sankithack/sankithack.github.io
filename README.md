# sankithack.github.io

Live: https://sankithack.github.io/

- **gchips gralloc explorer**: https://sankithack.github.io/gralloc/ (how Google gchips gralloc describes and allocates buffers, generated from AOSP `platform/hardware/google/gchips`).
- **AMDVLK Driver Atlas**: https://sankithack.github.io/vulkan/ (interactive walkthrough of AMD's open-source Vulkan driver stack, built from the real source).
- **Chess Strategy Academy**: https://sankithack.github.io/chess/ (interactive chess course: openings with variations, tactics, strategy, endgames and trainers).
- **Loci: Memory Training**: https://sankithack.github.io/memory/ (learn memory-palace, Major System, PAO and card techniques, then train with timed championship-style events, spaced-repetition trainers and a 4-week plan).
